# 手書きメモ

iPad + Apple Pencil で使う、手書き中心のメモ・議事録アプリ(Webアプリ / PWA)。

    起動する → 書く → あとで確認したいところを囲む → 一覧で見る → 確認済みにする

## 使い方

- **書く**: Apple Pencil で書く。指はスクロール専用(指では書けない)。
- **消しゴム**: 触れた線を1本単位で消す。
- **あとで確認**: ボタンを押してから、書いたところをペンで囲む。黄色く塗られ、「あとで確認」一覧に入る。囲むとペンに戻る。
- **フラグを外す**: メモの中の黄色い丸をタップ →「フラグを外す」。または一覧の「確認済み」。
- **元に戻す**: 書く・消す・フラグの操作を1つずつ戻せる。
- 保存は自動(書くたびに端末内へ保存)。

## ファイル構成(すべて同じ階層)

    index.html            画面(ホーム / 手書き画面)
    style.css             見た目
    app.js                画面遷移、メモ一覧、あとで確認一覧
    editor.js             手書き画面(ペン・消しゴム・囲んでフラグ・元に戻す・自動保存)
    render.js             描画の共通処理
    db.js                 端末内保存(IndexedDB)とデータ構造の説明
    sw.js                 オフライン用キャッシュ
    manifest.webmanifest  ホーム画面に追加したときの設定
    icon-180/192/512.png  アイコン

iPadからアップロードしやすいよう、フォルダを分けずに1階層にしている。
ビルド不要。依存ライブラリなし。

## 公開方法(GitHub Pages)

iPadのSafariからGitHubのリポジトリに全ファイルをアップロードし、Settings → Pages で main ブランチ / (root) を公開する。
URLは https://<ユーザー名>.github.io/<リポジトリ名>/ になる。

アプリを更新したら、変更したファイルを同じリポジトリにアップロードし直す(同じ名前のファイルは上書きされる)。
その際 `sw.js` の `CACHE` の番号(`tegaki-memo-v1` → `v2`)を上げる。更新は次回起動時に反映される。
**リポジトリ名(=URL)は変えないこと。** 変えるとそれまでのメモが見えなくなる。

## PCでの動作確認(PCがある場合)

    python3 -m http.server 8000

http://localhost:8000 を開く。マウスで書ける。localhost ではオフライン機能を止めている(確認するときは ?sw=1 を付ける)。

## データについて(重要)

- メモは **その iPad の中だけ** に保存される(IndexedDB)。PCとは同期しない。
- 保存先は **URLごと** に分かれる。配信先のURLを変えると、それまでのメモは新しいURLでは見えない。
- iPad では **Safari で開いた場合と、ホーム画面から開いた場合で保存場所が別** になる。普段は必ずホーム画面のアイコンから使うこと。
- 現時点ではバックアップ(書き出し)機能はない。

## 調整しやすい値(editor.js の先頭)

| 名前 | 内容 |
|---|---|
| PEN_WIDTH | ペンの太さ |
| ERASER_R | 消しゴムの大きさ |
| PALM_RADIUS | 手のひらとみなす接触の大きさ。誤スクロールが起きるなら小さく |
| AFTER_PEN_MS | ペンを離した直後、指操作を無視する時間 |
