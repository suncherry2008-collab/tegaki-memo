# 手書きメモ

iPad + Apple Pencil で使う、手書き中心のメモ・議事録アプリ(Webアプリ / PWA)。

    起動する → 書く → あとで確認したいところを囲む → 一覧で見る → 確認済みにする

## 使い方

記録は **1日 = 1つの記録** です。その日に書いたものは、何ページになってもその日の記録としてまとまります。

- **今日の記録**: ホームの「今日の記録」で今日の記録を開く。すでに書いていれば、最後のページが開く。
- **過去の日に追記**: 記録一覧、またはカレンダーで日付をタップするとその日の記録が開き、続きを書ける。カレンダーでは記録のない過去の日も開ける(書いたときに初めて保存される)。未来の日は開けない。
- **ページ**: 下のバーで切り替え(‹ ›)、「ページを追加」で最後に1ページ追加、「削除」で今のページを削除(確認あり・元に戻せない)。ページが1枚だけのときは削除できない。
- **ページの種類**: 下のバーの「罫線」ボタンで、そのページを罫線・方眼・無地から選べる(メモ・議事録は罫線、図や簡易設計図は方眼、など)。方眼は約5mmのマスで、5マスごとに少し濃い線。「ページを追加」すると今のページと同じ種類になる。その日の最初のページは罫線。
- **書く**: Apple Pencil で書く。指1本はスクロール専用(指では書けない・離すと少し滑る)。書いている間・ペンを離した直後・手のひらが触れたときは画面が動かない。ゆっくり書いたときだけ軽い手ぶれ補正が効く。
- **縮小・拡大**: 指2本でピンチ(1本目の指で動かし始めてからでもピンチになる)。縮めると1ページ全体が画面に収まるところまで、広げると3倍まで。等倍の近くで指を離すとぴったり等倍に戻る。縮小・拡大したままでも書ける。同じ日の中でページを切り替えても倍率は保つ。
- **色・太さ**: ツールバー左の丸(黒・赤・青)と線(細字・標準・太字)をタップ。タップするとペンに切り替わる。
- **蛍光ペン**: 「蛍光ペン」を選ぶと、ツールバー左が蛍光ペンの色(黄・ピンク・水色)に変わる。書いた文字の下に重なる(文字は隠れない)。止めると直線も使える。
- **まっすぐな線**: 線を引いたまま、ペンを離さずに少し止める(約0.6秒)と直線になる。そのまま動かすと終点がついてくる。水平・垂直に近いときはぴったり揃う。短い線やくねった線(文字など)は直線にならない。
- **消しゴム**: 2種類。消しゴムを選んだ状態でもう一度タップすると選べる。ボタンの文字で今の種類が分かる。
  - 部分消し: こすったところだけ消える(線の途中も消せる)
  - 線ごと消す: 触れた線を1本まるごと消す
- **あとで確認**: ボタンを押してから、書いたところをペンで囲む。黄色く塗られ、「あとで確認」一覧に日付・ページ番号つきで入る。一覧の「ページを開く」でその日のそのページが開く。
- **フラグを外す**: ページ内の黄色い丸をタップ →「フラグを外す」。または一覧の「確認済み」。
- **元に戻す**: 開いているページの中で、書く・消す・フラグの操作を1つずつ戻せる(ページを切り替えるとリセット)。
- 保存は自動(書くたびに端末内へ保存)。

## ファイル構成(すべて同じ階層)

    index.html            画面(ホーム / 手書き画面)
    style.css             見た目
    app.js                画面遷移、1日の記録(ページ切り替え・追加・削除・種類)、記録一覧、カレンダー、あとで確認一覧
    editor.js             手書き画面1ページ分(ペン3色3太さ・蛍光ペン・止めると直線・消しゴム2種類・ピンチ縮小拡大・囲んでフラグ・元に戻す・自動保存・誤スクロール対策)
    render.js             描画の共通処理
    db.js                 端末内保存(IndexedDB)、データ構造の説明、旧形式からの移行
    sw.js                 オフライン用キャッシュ
    manifest.webmanifest  ホーム画面に追加したときの設定
    icon-180/192/512.png  アイコン

iPadからアップロードしやすいよう、フォルダを分けずに1階層にしている。
ビルド不要。依存ライブラリなし。

## 公開方法(GitHub Pages)

iPadのSafariからGitHubのリポジトリに全ファイルをアップロードし、Settings → Pages で main ブランチ / (root) を公開する。
URLは https://<ユーザー名>.github.io/<リポジトリ名>/ になる。

アプリを更新したら、変更したファイルを同じリポジトリにアップロードし直す(同じ名前のファイルは上書きされる)。
その際 `sw.js` の `CACHE` の番号(`tegaki-memo-v1` → `v2`)を上げる。更新は次回起動時に反映される。
**リポジトリ名(=URL)は変えないこと。** 変えるとそれまでのメモが見えなくなる。

## PCでの動作確認(PCがある場合)

    python3 -m http.server 8000

http://localhost:8000 を開く。マウスで書ける。localhost ではオフライン機能を止めている(確認するときは ?sw=1 を付ける)。

## データについて(重要)

- 記録は **その iPad の中だけ** に保存される(IndexedDB)。PCとは同期しない。
- 以前の「メモ1件ずつ」の形式で書いたものは、初回起動時に「同じ日のメモ = その日の記録のページ(古い順)」として自動で移される。元のデータも消さずに残してある。
- 保存先は **URLごと** に分かれる。配信先のURLを変えると、それまでのメモは新しいURLでは見えない。
- iPad では **Safari で開いた場合と、ホーム画面から開いた場合で保存場所が別** になる。普段は必ずホーム画面のアイコンから使うこと。
- 現時点ではバックアップ(書き出し)機能はない。

## 調整しやすい値(editor.js の先頭)

| 名前 | 内容 |
|---|---|
| PEN_WIDTH | ペンの太さ |
| ERASER_R | 消しゴムの大きさ |
| PALM_RADIUS | 手のひらとみなす接触の大きさ。手のひらでスクロールするなら小さく、指のピンチが効かないなら大きく |
| AFTER_PEN_MS | ペンを離した直後、指操作を無視する時間 |
| HOLD_MS | 直線になるまでペンを止める時間。書いている途中で勝手に直線になるなら長く |
| MIN_LINE | 直線にする最短の長さ。文字の画が直線になってしまうなら大きく |
| PRESSURE_SMOOTH | 筆圧による太さ変化のなめらかさ |
| SMOOTH_MIN | 手ぶれ補正の強さ(1で補正なし、小さいほど強い) |
| PAN_START | 指がこれだけ動いたらスクロール開始(px) |
| FRICTION | 指を離したあとの滑り(1に近いほどよく滑る) |
| ペンの太さ | index.html の `data-width`(細字1.6 / 標準2.4 / 太字3.8) |
| MARKER_W | 蛍光ペンの太さ |
| MAX_ZOOM | 拡大の上限 |
